# psnine_next

PSNINE 增强用户脚本的新实现。源码按功能维护，发布为一个自包含 `.user.js`，面向桌面 **Tampermonkey（篡改猴）** 与 iOS/iPadOS Safari **Stay**。

本仓库为私有仓库，不依赖公开 CDN 或私有 raw URL 自动更新。
