## 二、核心功能深度归纳（对齐 80 项功能台账）

### 1. 奖杯模块 (Trophies: T01 - T14)
- **T08: 奖杯获得时间排序 (`trophySortByTimestamp` / `11f753d`, `ccc17f8`)**
  - **行为**：点击时间排序按钮在“初始XMB顺序”、“降序（最新在前）”、“升序（最早在前）”三态循环切换。
  - **实现细节**：从 DOM `em.alert-success` 读取时间文本或其 `tips` 属性提取年份（处理相对时间与跨年），计算 UTC 时间戳排序。
  - **风险**：P9 页面无获得时间的未获奖杯时间戳为 0，需稳定排在最后；DLC 分组表格独立排序，不可跨表格串位。
- **T10: 获得状态筛选（已获/未获）**
  - **历史事实**：旧版存在简单的奖杯筛选，但在提交 **`3f023d9`** 中被彻底移除（"remove trophy filter feature"）。
  - **当前规范**：在 `psnine_next` 80 项台账中，**T10 属于明确的重新规划与重构功能**，非旧插件现存功能。
- **T11 - T12: 奖杯 Tips 内联展开与批量加载 (`trophy_tips_inline` / `1126db7`、`3fcc952`、`d389442`)**
  - **行为**：README 未列出的功能。无需跳出奖杯列表页，直接点击单条奖杯行即可内联拉取该奖杯的完整 Tips（含点赞数、作者、回复和图文）。
  - **关键机制**：
    - `MutationObserver` 监听 `table.list` 变动（支持自动翻页后对新表格生效）。
    - 兼容新旧版本 P9 的 Tips HTML 结构（`b358b77`）。
    - 提供秘籍形式（快捷键）批量展开所有/未获奖杯 Tips（`3fcc952`）。
    - 针对内联载入的内容，独立实现黑名单与屏蔽词过滤（`1e67701`, `847ced4`, `35a7aa4`）。
    - 限制 `tipContainer` 最大滚动高度，并增加折叠切换箭头（`d389442`）。
  - **风险**：高频并发内联请求可能触发站点反爬限流；需建立队列与取消机制。
- **T13: Tips 点赞数热度排序 (`sortTipsByLikes` / `80889fb`, `af061ce`)**
  - **行为**：在奖杯 Tips 列表中按点赞“顶”数进行重排，使高价值白金攻略置顶。
- **移动端与现代排版彻底修复 (`304b14e`, `d3a8eb0`)**
  - 移除了容器写死 `min-width: 780px` 的旧样式，引入自适应 Flexbox 与 CSS 变量，彻底解决手机屏幕上奖杯图标重叠、类型徽章截断及图表溢出视口问题。

### 2. 游戏与个人进度模块 (Games: P01 - P14)
- **P04 - P06: 个人游戏进度缓存与后台 AJAX 异步更新 (`23f3762`, `b62c411`, `ade6202`)**
  - **行为**：在游戏列表（`/psngame`）、个人游戏库及主页中，为每款游戏显示用户本人的完成度百分比背景条与徽章。
  - **架构演进**：
    - 早期为前台同步串行拉取，导致页面卡顿且曾将他人完成度误记入缓存（`8f71e37`）。
    - kaikaiiiiiii 重构为后台异步 AJAX 请求（`23f3762`, `b62c411`），将进度存入 GM 缓存，并校验是否正在浏览本人页面。当前基线仍使用共享缓存键；新实现进一步按账号分区，防止账号切换污染。
    - 在 `ade6202` 中大幅优化更新触发策略：有进度变化才刷新，其余情况降低访问频次，有效减少站点 PV 压力。
- **P07: 白金成就光晕浮层 (`platinum_trophy_glow_aura` / `ed21088`)**
  - **行为**：为个人主页中已获得白金奖杯的游戏卡片增加华丽的发光浮层与高亮光晕，默认可配开关。
- **P08: 未注册用户主页同步引导 (`e757775`)**
  - **行为**：在未登录或非本人主页增加“同步”按钮引导，便于一键跳转官方同步接口。
- **P10 - P13: 关联跨版本/跨平台游戏导航 (`game_variant_references` / `75de1ae`, `cd1416a`, `8570c71`)**
  - **行为**：在单游戏页面与奖杯页面，自动识别该游戏的其他平台版本（PS4/PS5/Vita等）及不同发行地区（港版/日版/美版等），生成快捷跳转版本卡片，并提取对应版本的奖杯 Tips。
  - **缓存优化**：利用 `localStorage` 缓存游戏版本映射数据，过期时间设定为 1 天（`95b8db2`）。
- **P14: PSPC 与 PS5 封面及图标修复 (`game_pspc_icon_fix` / `b5c0b90`, `70d7276`, `6b9ccc0`)**
  - **行为**：PS5 与 PlayStation PC 封面比例与旧 PS3/PS4 不同，针对各页面修正其封面长宽比与对齐。
