# PSNINE 增强插件前期历史功能归纳报告 (Commits 001 ~ 389)

本报告基于对 `ToJ112/psnine-enhanced-version` 及其上游仓库前 389 条提交（2018-12-25 至 2020-10-03，版本从初始 Stylish CSS 演进至 v0.9.40）的逐条完整提交说明与完整源码差异（`git show --root -m`）的深度审计结果编制而成。

所有 389 条提交的逐条结构化审查记录已输出至 [early.json](early.json)。

## 一、功能领域分类归纳与证据链

### 1. 视觉主题与基础界面 (Theme & UI)

#### 1.1 夜间模式 (dark_theme)
- **首次证据 SHA**: `e1a15a9c356a817b27603089cb3568d3b9af0c45` (Initial commit)
- **关键演进 SHA**:
  - `81d71b34`: 发布 v1.1，增加黑条悬浮反白颜色。
  - `7d2b193b`: 制作独立的 `night-mode-css.js` 用户脚本（通过 `GM_addStyle` 注入）。
  - `889bd0f9`: 将夜间模式开关集成至设置面板，并在脚本内部动态注入夜间样式。
  - `7d7b8d0c`: 修复夜间模式覆盖刮刮黑条文字样式与楼中楼背景色问题。
  - `32ff1df4`: 升级夜间模式至 v1.9，重构色彩体系。
  - `6ebdbedc` / `bb67ba39`: 由 Nathaniel-Wu 优化白屏闪烁问题，改为 `@run-at document-start` 同步从 `localStorage` 读取并立刻挂载 `<style id="nightModeStyle">` 到 `document.head`。
- **功能行为**:
  - 全站覆盖深灰暗色背景（`#2b2b2b`、`#3d3d3d`），文字使用柔和灰色（`#bbb`），表格边框与列表分割线设为深灰。
  - 针对高亮行、管理行、不同背景色提供暗色调适配；对奖杯图标等按明度调优。
- **后续待核对问题 / 移动端注意事项**:
  - 手机端 Safari Stay 启动时，如果 `@run-at document-start` 注入过晚会产生瞬间白屏（FOUC）。在自包含架构中，需确保在读取到配置前优先保持默认背景或极轻量初始样式。

#### 1.2 自动夜间模式 (auto_night_mode)
- **首次证据 SHA**: `bb41569afc163ca1dfffbc58afb59f37555ab634` (v0.9.17)
- **关键演进 SHA**:
  - `fd657e5d`: 修复白天到来时夜间模式未能关闭的问题。
  - `c0057fd1`: 升级为多选模式（`SYSTEM` / `TIME` / `OFF`），支持通过 `window.matchMedia('(prefers-color-scheme: dark)')` 自动跟随系统。
- **功能行为**:
  - `SYSTEM`: 跟随操作系统深色模式设置，监听系统颜色模式变化自动切换。
  - `TIME`: 每日 19:00 至次日 07:00 自动开启夜间模式。
  - `OFF`: 不自动切换，完全由手动开关控制。

#### 1.3 刮条文字悬停显示 (hover_mask_reveal)
- **首次证据 SHA**: `e1a15a9c356a817b27603089cb3568d3b9af0c45` (CSS 实现)
- **关键演进 SHA**:
  - `d3d5f910`: 由纯 CSS 变为 JS `hoverUnmark` 配置化控制，鼠标悬停动态取父容器背景色并赋值给字体。
  - `3b3412c9`: 修复由于使用 ES6 箭头函数导致 jQuery `.hover()` 内 `this` 上下文丢失的 Bug。
- **功能行为**: 剧透黑条（`.mark`）平时底色与文字颜色一致（遮盖内容），鼠标悬停（hover）时反色显示。
- **后续待核对问题 / 移动端注意事项**:
  - 触屏移动端（iOS Safari）无 hover 事件，用户点击黑条容易触发页面跳转或误触。必须提供**点击切换显示/隐藏**（Tap to toggle）机制作为触屏替代。

#### 1.4 自定义美化滚动条 (custom_scrollbar)
- **首次证据 SHA**: `b3f0156f2d088cee6cc75b85989a292ec7ea3e8f`

#### 4.2 未获得奖杯筛选 (unearned_trophy_filter) 与 T10 奖杯筛选性质
- **首次证据 SHA**: `ac77c6a29ed8671a1eb3d0ebc4d260698aab455b` (v0.70)
- **关键演进 SHA**:
  - `8378d5cd` / `169b7cf6`: 优化“尚未获得”按钮样式与状态保持。

- **功能行为与属性说明 (主控特核)**:
  - **功能性质**: PSNINE 官方原生系统早期曾有简单的筛选链接或老版接口，后因官方页面结构调整或缺失便捷过滤入口，插件端在 `.dropmenu` 注入 `selectUnget` 按钮。

## 三、双端兼容性与后续落地核心技术核对

依据用户强调之技术路线（**桌面篡改猴 + 手机 Safari Stay 双兼容、单一自包含 .user.js、无外部 CDN、GM 异步/同步抹平、触屏替代悬浮、页面内设置入口**），梳理出以下关键架构核对点：

1. **彻底自包含与零运行时 CDN**:
   - 早期代码重度依赖 `@require` 外部 CDN（包括 jQuery 2.1.4, Highcharts, tippy.js, popper 等）。
   - 在新构建体系中，所有必要第三方库（如轻量图表或自研简易 Canvas/SVG 图表、轻量 Tippy/浮层逻辑）必须在构建期被打包为一个自包含的单文件 `.user.js`，不能在运行时发起 `@require` 或外部脚本加载，减少移动端 Safari Stay 对外部脚本网络的依赖；具体管理器和 iPhone 真机兼容性仍需验证。
2. **GM API 同步与异步双模式抽象 (Store & Context)**:
   - 早期直接同步调用 `window.localStorage` 或假定 `GM_getValue` 为同步返回。
   - 移动端 Stay 及现代油猴对 `GM.getValue` / `GM.setValue` 支持异步 Promise，而在桌面端经典油猴中又存在同步 `GM_getValue`。
   - 后续代码任务中的 `Store` 接口已拟定统筹同步缓存与异步持久化，确保两种环境下均不发生未定义崩溃或配置丢失。
3. **触屏替代悬浮交互 (Touch-Friendly Fallbacks)**:
   - 前期大量功能（`hover_image_preview`, `hover_mask_reveal`, `avatar_profile_hover`, `comment_hover_reply_btn`, `reply_content_preview`）是专为桌面端鼠标 `mouseenter` / `mousemove` / `mouseleave` 设计的。
   - 手机端触屏完全无法稳定触发 hover。落地方案必须实行双轨制：
     - 图片预览：默认启用 `showImagesInPosts` 内联排版，或点击图片链接弹出轻量模态画廊。
     - 刮条文字：点击黑条即反色显示，再次点击重新遮盖。
     - 用户资料与被回复卡片：点击卡片或专用小图标触发展开，点击空白处自动关闭。
4. **移动端页面内设置面板绝对可用**:
   - 桌面端可通过 Tampermonkey 菜单唤出设置，但手机端 Safari Stay 扩展菜单层级较深或无标准脚本菜单。
   - 必须保持固定的页面内入口（如头像菜单中的设置按钮，或页面边缘悬浮的极简齿轮图标），保证任何设备均能直达配置。
5. **Safari / WebKit 规范兼容**:
   - 严格避免在代码中使用 WebKit 兼容不良的特性（如早期在 commit 313 中踩坑的未转译可选链/正则后行断言等）。
   - 针对 `@run-at document-start`，做好 `document.readyState == 'loading'` 的渐进增强检测，防止在 DOM 未构建完成时访问页面元素引发致命异常。
