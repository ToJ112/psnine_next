## 复现与外部边界

README 中的开发命令可复现提交的测试。公开页面原文不入库；本机素材保存在 `.audit-cache/live/`，可直接运行 `node tools/replay-public-pages.mjs .audit-cache/live`。另一个环境需按素材清单的 URL 只读保存 HTML，并按文件名保存页面引用的四份 CSS；站点当前响应若与哈希不同，只能视为新的快照。回放把日期固定在 `2026-09-30`，计时器正常运行。

- 未修改现有脚本管理器安装，未实际执行签到、发帖或个人资料同步。自动签到默认关闭，手动同步只添加入口链接。
- 本次只读访问 `/huodong` 返回 404；活动页采用原源码的 `.store_box/.store_price/.store_tag_best` 结构夹具验证，不宣称当前活动页已在线实测。
- 汇率依赖 Frankfurter 公开接口或用户填写的带日期汇率；来源、日期及过期状态直接可见，原币种保留。
- 未确认登录身份时不建立“我的”进度；公开页无法确认个人状态时显示未知。跨版本奖杯无法明确对应时不生成猜测链接。
- 后台只读进度同步可完成缓存更新，但卸载后不更新页面；用户触发的封面进度查询和批量 Tips 可取消。
- 两个设备的设置默认独立，导出设置不含 Cookie 或进度缓存。私有仓库使用本地文件导入更新。
- 网站未来的 DOM、权限或接口变化仍可能影响用户脚本。
